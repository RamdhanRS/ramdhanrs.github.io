# Portfolio Ramdhan Ridho Saputra

Website portofolio statis untuk GitHub Pages, dibuat dengan HTML, CSS, dan JavaScript tanpa proses build.

## Struktur

```text
.
├── index.html
├── assets/
│   ├── style.css
│   └── script.js
├── LICENSE
└── README.md
```

## Menjalankan secara lokal

Buka `index.html` langsung di browser, atau jalankan server lokal dari folder repository:

```bash
python3 -m http.server 8000
```

Kemudian buka `http://localhost:8000`.

## Deploy ke GitHub Pages

1. Push seluruh perubahan ke branch `main`.
2. Buka **Settings → Pages** pada repository GitHub.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch `main`, folder `/ (root)`, lalu simpan.
5. Tunggu proses deployment selesai.

Untuk alamat `https://ramdhanrs85.github.io`, repository harus berada di akun GitHub `ramdhanrs85` dan bernama persis `ramdhanrs85.github.io`.
